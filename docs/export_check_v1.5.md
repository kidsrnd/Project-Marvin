# 내보내기 경로 점검 (2026-11-25)

교수님 11/23 피드백: 배포본과 구조가 같은 테스트 시트에 다섯 사례를 넣어 XLSX로 내보낸 뒤, 화면의 Q값 · 파일에서 읽은 Q값 · H~L로 다시 계산한 값을 비교한다. 배포본과 회수 원본은 수정하지 않는다.

## 방법
1. 배포본(교사1 판정지, 입력 없음)을 그대로 복사해 테스트 시트를 만들었다. 배포본·회수 원본은 건드리지 않았다.
2. 1~5번 줄에 다섯 사례를 넣었다.
3. 구글 시트 화면(API로 읽은 값)의 Q를 기록했다.
4. XLSX로 내보내 `openpyxl.load_workbook(data_only=True)`로 Q를 읽고, 같은 파일의 H~L로 `check_v15.usable()`을 다시 계산했다.

## 결과
| 판정지 번호 | 사례 | 화면 Q | 파일 Q (data_only) | H~L 재계산 | Q 수식 유지 |
|---|---|---|---|---|---|
| 1 | 치명 있음 + 보류 (H 있음, I 보류) | 사용 불가 | 사용 불가 | 사용 불가 | 예 |
| 2 | 치명 없음 + 중대 보류 (J 보류) | 미확정 | 미확정 | 미확정 | 예 |
| 3 | 객관식 아님 (서술형, I·J 해당 없음, L 있음) | 고치면 사용 | 고치면 사용 | 고치면 사용 | 예 |
| 4 | 전부 없음 | 그대로 사용 | 그대로 사용 | 그대로 사용 | 예 |
| 5 | 빈칸 (I 빈칸) | (빈칸) | None | (빈칸) | 예 |

- 세 값이 다섯 사례 모두 같았다. H~L이 다 채워졌는데 파일의 Q가 비어 있는 줄은 없었다.
- XLSX에서 Q 빈칸은 `""`가 아니라 `None`으로 읽힌다. 검사기는 `value or ""`로 처리하므로 문제없다.
- XLSX에서 판정지 번호가 `1.0` 같은 숫자로 읽힌다. 번호 누락·중복 검사를 문자열로 하면 30개 전부 누락으로 나온다 → `check_v15.py`에서 번호를 정수로 바꾼 뒤 1~30 누락·중복을 검사하도록 고쳤다(판정 규칙은 그대로).
