# 평가자용 문구 대조표 (v1.4 → v1.5)

작성: 2026-11-16 · 대상: 교사별 판정지(구글 시트 '판정' 탭 머리글), 교사 가이드('가이드' 탭), 평가 기준(eval_criteria v1.4 → v1.5)
판정지는 11/15 교사별 구글 시트로 배포했다. 11/16, 세 교사 모두 독립 판정을 시작하기 전에 같은 내용으로 고쳤고, 이후 고정한다(링크 동일).

## 바꾼 이유
- **I·J 명칭**: 두 이름이 같은 말처럼 읽혔다. I는 "그 오답도 맞다", J는 "맞는지 틀린지 판가름이 안 난다"로 차이를 이름에 드러냈다. 정의는 v1.4와 같다.
- **K 범위**: 정답이 본문 근거에 약한 감정 문항에서, 학생이 다른 선지를 상식으로 지우고 정답을 고르는 경우가 있었다. 본문을 읽지 않고 풀리는 경우를 문제 문장 속 답에 한정하지 않고 상식·통념까지 넓혔다. 범위가 바뀌었으므로 기준 변경으로 기록한다.
- **'어디를 보나'**: 오류가 질문에서 나오는지, 정답·오답 선지에서 나오는지가 문항마다 다르다. 기준을 만든 연구자도 1차 판정에서 칸마다 판단 대상이 문항마다 달라졌다. 판정자들이 같은 곳을 보고 판단해야 평가자 간 일치도를 볼 수 있으므로, 칸마다 볼 곳을 머리글에 표시했다.
- **Q 자동 계산**: 판정자가 직접 고르면 오류 칸과 Q가 어긋날 수 있다(연구자 1차 판정에서 실제로 발생). 규칙은 그대로 두고 계산만 자동으로 했다.

## 정리
- v1.5는 K 범위 때문에 **표현 정비가 아니라 기준 변경**이다. 나머지는 표현 정비다.
- 변경은 모두 외부 교사 독립 판정 **전**이며, 세 교사에게 같은 최종본을 반영한 뒤 고정한다.
- 연구자 판정은 30문항 전체를 v1.5로 다시 판정했다(교사 판정을 보기 전). 1차 원본(judge_sheet_v5_1차30_연구자.xlsx)은 보존하고, 연구자 구글 시트 '변경 이력' 탭에 기준 변경과 재판정 사유를 남겼다.
- 연구자 재판정 결과(30문항): 그대로 사용 19, 고치면 사용 7, 사용 불가 3, 미확정 1. 연구자 판정은 교사 간 일치율에 넣지 않는다.
