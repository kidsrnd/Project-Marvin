# 배포본·집계 규칙 대조표 (v1.5)

작성: 2026-11-18 · 교수님 11/17 피드백 1번(배포본과 집계 코드의 일치) 점검 기록

## 1. 무엇을 대조했나
| 대상 | 내용 | 상태 |
|---|---|---|
| 기준 문서 | `docs/eval_criteria_v1.5.md` 3절 (사용 가능 여부) | 고정 |
| 배포본 | 교사 3인·연구자 구글 시트 '판정' 탭 Q2:Q31 수식 (보호 범위, 판정자 수정 불가) | 고정. 11/16 이후 수정하지 않음 |
| 기존 검사기 | `make_blind.py` v7 `--check` (v1.4 규칙) | 판정지 생성 당시 기록으로 보존. 집계에 쓰지 않음 |
| 새 검사기 | `check_v15.py` (v1.5 규칙) | 회수한 판정지를 집계하기 전 검사에 사용 |

배포본 Q열 수식 (2행 기준, 31행까지 같은 형태):

```
=IF(COUNTIF(H2:L2,"")>0,"",
 IF(COUNTIF(H2:I2,"있음")>0,"사용 불가",
 IF(COUNTIF(H2:L2,"판단 보류")>0,"미확정",
 IF(COUNTIF(J2:L2,"있음")>0,"고치면 사용","그대로 사용"))))
```

계산 순서: 빈칸 확인 → 치명(H·I) '있음' → H~L '판단 보류' → 중대(J·K·L) '있음' → 그대로 사용.
v1.5 3절의 순서와 같다.

## 2. 다섯 사례 대조
`python check_v15.py --selftest` 결과. 배포본 수식은 같은 입력을 수식 순서대로 계산한 값이다.

| 사례 | H | I | J | K | L | v1.5 기준 (예상) | 배포본 수식 | check_v15.py | 기존 --check (v1.4) |
|---|---|---|---|---|---|---|---|---|---|
| ① 치명 있음 + 다른 칸 보류 | 있음 | 없음 | 판단 보류 | 없음 | 없음 | 사용 불가 | 사용 불가 | 사용 불가 | **모순 경고** ('미확정'을 요구) |
| ② 치명 없음 + 중대 보류 | 없음 | 없음 | 없음 | 판단 보류 | 없음 | 미확정 | 미확정 | 미확정 | 통과 |
| ③ 전부 없음 | 없음 | 없음 | 없음 | 없음 | 없음 | 그대로 사용 | 그대로 사용 | 그대로 사용 | 통과 |
| ④ 빈칸 | 없음 | 없음 | (빈칸) | 없음 | 없음 | 계산 안 함 (미판정) | 빈 값 | 계산 안 함 | 통과 (빈칸 경고는 따로 냄) |
| ⑤ 객관식 아님 | 없음 | 해당 없음 | 해당 없음 | 없음 | 있음 | 고치면 사용 | 고치면 사용 | 고치면 사용 | 통과 |

- 배포본 수식과 `check_v15.py`는 다섯 사례 모두 v1.5 기준과 일치한다.
- 기존 `--check`는 사례 ①에서만 어긋난다. v1.4는 "치명·중대에 보류가 있으면 미확정"이었고, v1.5는 "치명 '있음'이 확정되면 다른 칸의 보류와 관계없이 사용 불가"이기 때문이다.
- 실제 판정지에서 사례 ①에 해당하는 예: 연구자 판정 26번(H 있음, I 판단 보류 → 사용 불가).

## 3. 기존 --check를 그대로 쓰면 생기는 문제 두 가지
1. 사례 ①을 모순으로 경고한다 (위 표).
2. Q열이 이제 수식이다. 기존 `--check`는 판정지를 값이 아니라 수식 그대로 읽어서(`data_only` 없음), 수식 문자열을 '미확정이 아닌 값'으로 보고 보류가 있는 모든 문항을 모순으로 경고한다. `check_v15.py`는 계산된 값을 읽는다.

## 4. 조치
- 배포한 구글 시트는 고치지 않는다 (기준·수식·문항 순서 보존).
- `make_blind.py`는 v7 판정지를 만든 기록으로 그대로 둔다. 집계 전 검사는 `check_v15.py`로 한다.
- 진행 중인 판정값은 검사기에 맞춰 바꾸지 않는다. `check_v15.py`가 불일치를 내면 판정값이 아니라 원인(수식 손상, 내려받기 오류 등)을 확인한다.
- `check_v15.py`는 H~L 외에 F·M·N 빈칸도 미판정으로 경고한다. 배포본 수식은 H~L만 보고 Q를 계산하므로, M·N이 비어 있어도 Q는 나올 수 있다. 이 경우도 집계 전에 미판정으로 걸러진다.
