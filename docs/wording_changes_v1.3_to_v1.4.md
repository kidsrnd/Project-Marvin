## 정리
- v1.4는 **표현 정비가 아니라 기준 변경**이다(J 범위, Q 선택지, 보류·지적·일치율 집계). "판정 기준은 v1.3 유지"로 기록하지 않는다.
- 변경은 모두 외부 교사 독립 판정 **전**이며, 모든 교사에게 같은 최종본(판정지 v7, 가이드 v4)을 배포한 뒤 고정한다.
- 연습 사례(가이드 v4, 본 평가 30문항과 무관한 Tom 지문 3문항)로 J·M·I 경계가 의도대로 판정되는지 먼저 확인한다. 연습에서 판정이 같아도 모든 문항에서 동등하다는 보장은 아니다.
- 연구자 판정 1~10번은 v1.4 문구로 재확인하고, 바뀐 칸은 judge_sheet_v7_1차30_연구자.xlsx '변경 이력' 탭에 기록한다. 원본(v5)은 보존.
