# 교사 평가 기준 v1.2 (2026-10-31, 외부 교사 판정 시작 전 개정)

교수님 5주차 피드백 반영. 이 기준은 교사 판정이 끝날 때까지 바꾸지 않는다.

## 1. 판정 순서
1. 판정자는 조건명·전후 짝·검수기 지적을 모두 보지 않은 상태로 본문과 문항만 보고 판정한다 (조건명 비공개 판정). 연구자는 기존 결과를 알고 있으므로 완전한 블라인드로 표현하지 않으며, 연구자 판정과 외부 교사 판정은 파일을 나눠 따로 저장한다.
2. 근거가 되는 본문 문단 번호를 기록한다 (evidence.py의 paragraph 번호와 동일).
3. 교사 2명이 독립 판정 → 합의 전 일치율과 불일치 사례 기록 → 합의 판정 확정.
4. 그다음에 검수 로그(review_link.csv)와 대조한다.

## 2. 문항 오류 기준
| 등급 | 항목 | 적용 유형 | 정의 |
|---|---|---|---|
| 치명 | 본문 근거 없는 정답 | 전체 | 정답이 본문의 대사·행동·서술로 뒷받침되지 않음. 감정 문항은 해당 장면의 행동·대사로 그 감정을 설명할 수 있으면 오류 아님. 다른 감정도 동등하게 가능하면 오류 |
| 치명 | 정답 선지 2개 이상 | 객관식만 | 다른 선지도 정답으로 인정됨. 서술형의 여러 타당한 표현은 오류 아님 |
| 중대 | 본문만으로 구별 안 되는 오답 | 객관식만 | 본문으로 그 오답이 틀렸음을 확인할 수 없음 |
| 중대 | 문제 문장 안에 답이 있음 | 전체 | 본문을 읽지 않고 문제 문장만으로 답을 고를 수 있음 |
| 중대 | 본문 표현 그대로 → 그 문장만 찾으면 풀림 | 전체 | 문제(또는 정답 선지)의 본문 표현을 찾아 그 옆 문장만 보면 이해 없이 답이 나옴. 본문 단어 사용 자체는 오류 아님 |
| 참고 | 본문에 없는 내용의 오답 | 객관식만 | 오답 선지가 본문에 나오지 않음. 수능식 오답으로는 정상이며 문항 오류가 아님. B1 설계 규칙(R2) 준수 여부 기록용 |
| 경미 | 어휘·길이 | 전체 | Pupa 레벨(국내 중학 수준, 교육부 기본 어휘 2,000단어 = 초등 800 + 중·고 공통 1,200) 초과 어휘, 지나치게 긴 문제 |

### 판정 값
- 오류 칸마다 **있음 / 없음 / 판단 보류** 중 하나를 고른다. 객관식 전용 칸은 단답·서술형에서 **해당 없음**(자동).
- 빈칸 = 미판정. 빈칸이 남은 판정지는 집계하지 않는다 (`make_blind.py --check`).

## 3. 사용 가능 여부
- 그대로 사용: 치명 0, 중대 0 (경미·참고 허용)
- 고치면 사용: 치명 0, 중대 1 이상
- 사용 불가: 치명 1 이상

'치명 오류 없음'과 '사용 가능'은 다르다.

## 4. 별도 축 (오류와 분리)
- 서사 요소 (FairytaleQA 7종): 인물·배경·사건·감정·인과·결말·예측
- 명시 / 암시
- '감정'·'암시' 태그는 오류 판정과 무관하다.

## 5. 검수기 지적 분류 (지적 단위)
| 분류 | 정의 |
|---|---|
| 기존 규칙 위반 | B1 생성 프롬프트에 있던 규칙(R1~R5)을 어긴 것을 지적 |
| 새 요구사항 | B1 생성 프롬프트에 없던 기준(예: 15단어 길이)을 적용한 지적 |
| 근거 없는 지적 | 교사 판정상 해당 문제가 실제로 없음 |

## 6. 집계 (분모를 섞지 않는다)
- **문항 단위 검출률** = 교사가 결함 있다고 판정한 수정 전 B1 문항 중, 검수기가 그 결함을 맞게 지적한 문항 수
- **문항 단위 오탐률** = 교사가 결함 없다고 판정한 수정 전 B1 문항 중, 검수기가 결함 있다고 지적한 문항 수
- **지적 단위 정밀도** = 검수기 지적 28건 중 교사 판정상 타당한 지적 수 (5절 분류와 함께)
- **수정 성능** (같은 question_id 15쌍): 결함→정상 / 정상→결함 / 결함→결함(기존 오류 잔존 · 새 오류 발생 구분) / 정상→정상(표현 변경 시 필요성·의미 보존 여부 별도 기록)
- 모든 결과는 **생성 건수 기준**과 **고유 문항 기준**(문제 문장 단어 80% 이상 겹침 = 같은 문항)을 함께 제시한다.

## 7. 단어 겹침 풀이기
- 정답률과 동점 처리 규칙(최고점 동점 = 오답 처리)을 함께 보고한다.
- 우연 수준(2.25/9)과 차이를 확인하지 못한 것은 같은 성능을 입증한 것이 아니다. 교사 판정과 어긋난 문항을 개별적으로 본다.
